# Third-party software

Monitor Switch code is MIT licensed. It has no paid service, account, or telemetry. Direct DDC control works locally. The optional paired Windows helper uses the local network to control both monitors from the Mac.

- **winddc:** copyright attribution is included in `licenses/winddc-MIT.txt`. The NVIDIA packet and monitor association follow [winddc](https://github.com/choplin/winddc/tree/9d897ea5ecd314b99fd0757664e1ccb50efd448e), MIT licensed. NVIDIA's installed driver is loaded separately; no NVIDIA SDK or driver DLL is distributed.

- **PySide6-Essentials / Qt 6.12.0 / Shiboken6:** installed from PyPI. These components have their own licenses, including LGPLv3/GPLv3 or commercial options. This application uses the open-source distribution and dynamically loaded Qt libraries. See [Qt for Python licensing](https://doc.qt.io/qtforpython-6/licenses.html) and [Qt licensing](https://www.qt.io/licensing/open-source-lgpl-obligations). Qt source is available from [Qt's source archive](https://download.qt.io/archive/qt/), and [PySide source](https://code.qt.io/cgit/pyside/pyside-setup.git/). LGPLv3 and GPLv3 license texts are included in the licenses directory. Notices supplied with the wheel remain in the Python environment. Source code and build instructions for this application are provided so users can rebuild with modified libraries. Keep the bundled shared libraries replaceable. Before public distribution, include the relevant Qt license texts and complete third-party notices for the build you distribute.
- **m1ddc:** copyright (c) 2021 waydabber, MIT. Pinned to [7339ceebb03f691b1eaeb8471dca301d215d19c8](https://github.com/waydabber/m1ddc/tree/7339ceebb03f691b1eaeb8471dca301d215d19c8). The setup script includes its full license. Our patch validates Get VCP replies, corrects a two-byte read buffer length, and preserves zero-checksum packet bytes. The patch source and validator are in `scripts/patch_helpers.py` and `native/ddc_reply.h`.
- **ddcctl:** GPLv3, separately downloaded and built by the setup script on Intel Macs. Pinned to [06c7ab6eba5b1c903678f8113a92cef990acaf90](https://github.com/kfix/ddcctl/tree/06c7ab6eba5b1c903678f8113a92cef990acaf90). Our patch adds stable UUID selection. If distributing an Intel build containing this helper, comply with its GPLv3 license and supply the corresponding helper source plus this patch and build instructions. No Intel binary is shipped in the Apple Silicon build.
- **PyInstaller:** build tool, GPLv2 with an exception allowing bundled applications to use their own licenses. See [PyInstaller license](https://pyinstaller.org/en/stable/license.html).
- **Python:** [PSF license](https://docs.python.org/3/license.html). A packaged build embeds a Python runtime.
- **cryptography / cffi:** release signatures use the cryptography library (Apache-2.0 or BSD-3-Clause) and its OpenSSL implementation. cffi uses the MIT license. Their distribution metadata and bundled license texts are retained in packaged builds.

This is a local development build, without Developer ID signing, notarization, or a Windows signing certificate. It is runnable locally; it is not a store release.

- **Lucide icons:** bundled SVG icons from the official Lucide repository. The complete ISC license and applicable Feather MIT notices are in `licenses/lucide-LICENSE.txt`. Exact source revisions and hashes are recorded in `assets/provenance.json`.
- **Noto Sans KR:** bundled unmodified font from Google Fonts, copyright Adobe. The SIL Open Font License 1.1 is included in `licenses/NotoSansKR-OFL.txt`. The font is available to the application without a network request.
